# 常见问题（FAQ）

## 打印相关

### 网页打印和本地打印有什么区别？

- **网页打印**：文件上传到服务器，服务器转换 / 渲染后打印
- **本地打印**：客户端电脑自己安装驱动，服务器只转发打印数据

网页打印不需要在每台设备安装驱动，适合手机和临时电脑。

### PPD 队列和 RAW 队列有什么区别？

| 队列 | 数据 | 使用场景 |
|---|---|---|
| PPD | PDF / PostScript，服务器 PPD 渲染 | 网页打印、IPP Everywhere 免驱 |
| RAW | 打印机原生数据，服务器直接转发 | 本地已安装 PPD 驱动的客户端 |

本地已装驱动的客户端应使用 RAW 队列。

### 本地 PPD 打印失败，提示格式错误

确认连接的是 RAW 队列：

```text
ipp://<主机 IP>:8631/printers/<name>-raw
```

如果连接到 PPD 队列，客户端发送的 PJL/PCL 数据会被服务器错误地再次过滤。

### 打印出来的页面尺寸不对 / 数据量很大

检查 PDF 页面尺寸。某些导出文件会把图片像素当成 PDF point，例如出现：

```text
2100 x 2920 pts
```

这类文件接近 74cm × 103cm，而不是 A4。

解决办法：

- 网页打印：选择 A4 + 自动缩放
- 本地 PPD 驱动：打印时选择 A4 + 适合页面
- 或先使用 Ghostscript / WPS 将 PDF 归一化为 A4

### 页码范围怎么填？

支持：

```text
1-2
1-5 8
1-2,4
```

不能超过文件实际页数。PDF 页数在浏览器中读取；Office 文件在服务端转换后校验。

### 打印机一直显示“正在向打印机发送数据”

依次检查：

1. 打印机是否缺纸 / 卡纸
2. 打印机电源和 USB 连接
3. 打印机面板是否有错误
4. `lpstat -p` 查看 CUPS 状态
5. 必要时重启打印机后再提交

## 任务与队列

### 「清空队列」和「清空打印记录」有什么区别？

- **清空队列**：取消该打印机 PPD + RAW 队列中当前任务
- **清空打印记录**：删除应用任务历史，并同步清理 CUPS 历史

### 清空打印记录会删除 CUPS 历史吗？

会。执行时会短暂设置：

```text
PreserveJobHistory=No
PreserveJobFiles=No
```

清空后立即恢复为 `Yes`，之后新的 CUPS 历史会继续保留。

### 任务数量很多 / 出现重复本地任务

本地 CUPS 在打印机不可用时可能自动重试，生成新的 CUPS job。  
当前版本只导入活动中的本地任务，并跳过 0 字节任务；已完成本地历史不会自动重复导入。

## 网络与安全

### 为什么 RAW 队列不能暴露公网？

RAW 队列不做格式处理，任何人发送任意数据都会被直接送到打印机，可能导致：

- 一直打印乱码
- 浪费纸张
- 打印机缓冲堵塞

安全建议：

- 不要将 8631 端口映射到公网
- 只允许局域网网段访问 8631
- 公网只暴露 Web 入口

### 管理页打不开 / 一直要求 Token

管理页需要 `ADMIN_TOKEN`。检查：

- 容器环境变量是否设置
- 是否修改了默认值
- 浏览器是否缓存了旧 token

### 局域网其他电脑添加打印机失败

检查：

- 两台设备在同一网段
- 主机防火墙允许 8631
- 打印机在管理页已开启「允许访问」
- IPP 地址中的队列名正确

## 维护

### 如何备份？

停止写入或选择低峰期，备份：

```text
data/
cups-etc/
cups-spool/
cups-log/
```

### 如何查看日志？

```bash
docker compose logs -f print-portal
docker exec print-portal tail -n 100 /var/log/cups/error_log
```

### 如何更新？

```bash
docker compose pull        # 如果使用镜像
docker compose up -d --build
```

更新前建议备份 `data/` 和 `cups-etc/`。
