# Print Portal 用户使用指南

本文面向日常使用者，说明如何从网页打印、管理打印机，以及如何在本地电脑/手机上添加打印机。

## 1. 打开打印页

在局域网浏览器访问：

```text
http://<NAS 或主机 IP>:8088/
```

例如：

```text
http://192.168.2.30:8088/
```

管理页需要管理员 Token：

```text
http://<主机 IP>:8088/admin
```

## 2. 网页打印

### 2.1 上传文件

支持：

- PDF
- JPG / PNG / WebP
- Word（.doc / .docx）
- Excel（.xls / .xlsx）
- PPT（.ppt / .pptx）
- PostScript

单次只能上传一个文件，默认最大 200MB。

上传后：

- 上传控件自动隐藏
- 直接显示 PDF / 图片预览
- 右上角 `×` 可以移除文件并恢复上传控件

### 2.2 设置打印参数

| 参数 | 说明 |
|---|---|
| 页码范围 | 如 `1-2`、`1-5 8`；不能超过文件页数 |
| 份数 | 1–99 |
| 双面 | 单面 / 双面长边 / 双面短边 |
| 纸张 | A4、A5、Letter 等；以打印机 PPD 支持为准 |
| 方向 | 纵向 / 横向 |
| 颜色 | 只有打印机支持彩色时显示 |
| 缩放 | 自动 / 适应页面 / 填满页面 / 原始大小 |

点击「打印」后任务会进入后台队列，可以离开页面。任务列表每 3 秒自动刷新。

### 2.3 页码范围限制

PDF 会在浏览器中读取实际页数；图片按 1 页处理。

例如文件共 38 页：

```text
全部（共 38 页），如 1-2
```

输入 `1-100` 会提示：

```text
页码范围不能超过文件页数（共 38 页）
```

Word / Excel / PPT 的页数在服务端转换后校验，非法范围会导致任务失败并显示错误。

## 3. 任务管理

管理后台 →「任务」：

- 按状态筛选：待处理、转换中、已提交、排队中、打印中、已完成、失败、已取消
- 按来源筛选：网页 / 本地
- 搜索框：支持文件名、用户、状态，输入后 300ms 自动搜索
- 操作：
  - 查看文件（网页任务）
  - 取消、暂停、恢复、重新打印
- 「清空打印记录」：删除已完成 / 失败 / 已取消记录，并同步清理 CUPS 历史

## 4. 打印机管理

管理后台 →「打印机」：

- 「添加打印机」：扫描 USB / 局域网设备，选择驱动
- 「编辑」：修改名称、驱动、默认打印机、局域网访问
- 行末 `⋯` 菜单：
  - 设备维护
  - PPD 默认选项
  - 清空队列
  - 删除打印机

### 4.1 USB 打印机

1. 将打印机 USB 连接到宿主机
2. 管理页点击「添加打印机」
3. 选择扫描到的 USB 设备
4. 选择型号对应 PPD
5. 保存

### 4.2 局域网打印机

1. 打印机与 NAS 在同一局域网
2. 添加打印机 → 扫描局域网 / 手动填写 IPP 地址
3. 支持 IPP Everywhere 时勾选「免驱动」
4. 否则选择 PPD 或上传 PPD

### 4.3 两个队列

每台打印机会创建：

```text
<name>-ppd
<name>-raw
```

- 网页打印使用 PPD 队列进行驱动渲染
- 本地已安装驱动使用 RAW 队列
- 支持 IPP Everywhere 的客户端可使用 PPD 队列

## 5. 本地电脑使用

### 5.1 macOS

#### 本地已有 Brother PPD 驱动

系统设置 → 打印机与扫描仪 → 添加打印机 → IPP：

```text
地址：<主机 IP>
队列：<name>-raw
协议：IPP
驱动：Brother DCP-7060D（或对应型号）
```

或使用命令行：

```bash
lpadmin -p DCP7060D-LAN -E \
  -v ipp://<主机 IP>:8631/printers/<name>-raw \
  -P /path/to/br7060d.ppd
```

#### 免驱 / IPP Everywhere

```text
地址：<主机 IP>
队列：<name>-ppd
协议：IPP
使用：IPP Everywhere
```

### 5.2 Windows

添加打印机 → 使用 IPP 地址：

```text
http://<主机 IP>:631/printers/<name>-raw   # 已安装厂商驱动
```

或使用 IPP Everywhere 连接 PPD 队列。实际端口以管理页「共享」页显示为准。

### 5.3 为什么本地 PPD 驱动要用 RAW

本地 PPD 驱动在客户端已经完成渲染，发送的是 PJL / PCL 等打印机原生数据。  
RAW 队列不做格式处理，直接转发给打印机，因此不会重复渲染。

如果把本地驱动数据发到 PPD 队列，服务器会再次按 PPD 过滤，可能报错或格式错误。

## 6. 共享给其他局域网用户

管理后台 →「共享」：

- 显示 Web 地址和 PPD / RAW 地址
- 可控制「允许访问」和「允许发现」
- 允许访问关闭后，IPP 网关会拒绝该打印机

共享前确认：

- 对方在同一局域网
- 防火墙允许访问 8088 和 8631
- 不要把 8631 暴露到公网

## 8. 安全提示

- 修改默认 `ADMIN_TOKEN`
- 不要将 RAW 队列暴露到公网
- 建议只允许局域网网段访问 8631
- 定期备份数据和 CUPS 配置
